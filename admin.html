Langkah Aktivasi Supabase

  1. Buat proyek Supabase baru dan jalankan supabase/schema.sql (ganti <ADMIN_EMAIL> dengan email admin).
  2. Nonaktifkan public sign-up pada Authentication -> Providers -> Email, lalu buat 1 user admin.
  3. Salin .env.example menjadi .env dan isi VITE_SUPABASE_URL serta VITE_SUPABASE_ANON_KEY.
  4. Jalankan ulang server Vite agar variabel env terbaca.

Masuk Admin CMS

Hanya akun email terdaftar pada policy RLS PostgreSQL yang diizinkan mengubah data.
